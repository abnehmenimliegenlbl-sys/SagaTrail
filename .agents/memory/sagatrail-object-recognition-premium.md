---
name: SagaTrail object recognition premium
description: Product boundary for the planned camera-based object recognition and web lookup feature.
---

Photo-based recognition of hiking-relevant outdoor objects is a Premium feature. It is on-demand, returns ranked candidates for user confirmation, and may enrich a confirmed result with location-aware OSM/Wikimedia/web information. Generic everyday objects are intentionally excluded.

**Why:** General image recognition and follow-up web lookup add external processing cost and are intentionally part of SagaTrail's paid value rather than the basic hiking flow.

**How to apply:** Reuse the existing premium entitlement gate before capture/upload and keep recognition separate from the free GPS/compass/AR fallback. Restrict candidates to mountains, landforms/geology, plants, animals, buildings/landmarks, trail signs/infrastructure, and water features. Do not identify people or present uncertain matches as facts.
